# Salesforce API Reference

This document captures the specific Salesforce APIs, endpoints, and authentication details the plugin will use. All information verified against current GA documentation.

---

## Agent API (Headless Conversations)

**Base path**: `https://{MY_DOMAIN}.my.salesforce.com/einstein/ai-agent/v1/`
**Status**: Generally Available
**Purpose**: Interactive headless agent conversations (exploratory testing)

### Endpoints

| Operation | Method | Path |
|---|---|---|
| Create session | POST | `/einstein/ai-agent/v1/agents/{agentId}/sessions` |
| Send message (sync) | POST | `/einstein/ai-agent/v1/sessions/{sessionId}/messages` |
| Send message (streaming) | POST | `/einstein/ai-agent/v1/sessions/{sessionId}/messages/stream` |
| End session | DELETE | `/einstein/ai-agent/v1/sessions/{sessionId}` |
| Submit feedback | POST | `/einstein/ai-agent/v1/sessions/{sessionId}/feedback` |

### Create Session

```http
POST /einstein/ai-agent/v1/agents/{agentId}/sessions
Authorization: Bearer {accessToken}
Content-Type: application/json

{
  "externalSessionKey": "uuid-v4-string",
  "bypassUser": false
}
```

- `agentId`: 18-character Salesforce ID (prefix `0Xx`)
- `externalSessionKey`: UUID generated by the client
- `bypassUser`: If `true`, runs as the agent's configured user instead of the OAuth token user

**Response**: Returns `sessionId` to use in subsequent calls.

### Send Message (Synchronous)

```http
POST /einstein/ai-agent/v1/sessions/{sessionId}/messages
Authorization: Bearer {accessToken}
Content-Type: application/json

{
  "message": {
    "sequenceId": 1,
    "type": "Text",
    "text": "I need help with my order"
  }
}
```

- `sequenceId`: Incrementing integer per message in session (starts at 1)
- Returns complete response in single HTTP response

### Send Message (Streaming / SSE)

```http
POST /einstein/ai-agent/v1/sessions/{sessionId}/messages/stream
Authorization: Bearer {accessToken}
Accept: text/event-stream
Content-Type: application/json

{
  "message": {
    "sequenceId": 1,
    "type": "Text",
    "text": "I need help with my order"
  }
}
```

**SSE Event Types**:

| Event | Purpose |
|---|---|
| `ProgressIndicator` | Agent is processing (thinking indicator) |
| `TextChunk` | Partial text response |
| `Inform` | Complete response message |
| `EndOfTurn` | Agent finished responding, ready for next input |
| `ValidationFailureChunk` | Input validation error |

### End Session

```http
DELETE /einstein/ai-agent/v1/sessions/{sessionId}
Authorization: Bearer {accessToken}
```

### Constraints

- **NOT supported** for "Agentforce (Default)" type agents -- custom agents only
- Sessions may time out after extended inactivity
- Each message requires incrementing `sequenceId`

## Testing API (Batch Evaluation)

**Base path**: `https://{MY_DOMAIN}.my.salesforce.com/services/data/v63.0/einstein/ai-evaluations/`
**Status**: Generally Available (API v63.0+)
**Purpose**: Structured batch testing with pass/fail verdicts

### Endpoints

| Operation | Method | Path |
|---|---|---|
| Start test run | POST | `/services/data/v63.0/einstein/ai-evaluations/runs` |
| Get run status | GET | `/services/data/v63.0/einstein/ai-evaluations/runs/{runId}` |
| Get run results | GET | `/services/data/v63.0/einstein/ai-evaluations/runs/{runId}/results` |

### Start Test Run

```http
POST /services/data/v63.0/einstein/ai-evaluations/runs
Authorization: Bearer {accessToken}
Content-Type: application/json

{
  "aiEvaluationDefinitionName": "My_Agent_Test"
}
```

Test runs are asynchronous. Poll status until complete.

### AiEvaluationDefinition Metadata

The metadata type that defines test cases. Created from YAML specs via `sf agent test create`.

**YAML test spec structure** (input format):

```yaml
type: agent
subjectApiName: My_Agent
testCases:
  - utterance: "I need to return a product"
    expectedTopic: "Returns_and_Exchanges"
    expectedActions:
      - "Identify_Order"
      - "Process_Return"
    expectedOutcome: "Agent should identify the order and initiate return process"
    conversationHistory:
      - role: "user"
        content: "Hi, I bought something last week"
      - role: "assistant"
        content: "Hello! I'd be happy to help you with your recent purchase."
```

**Deployed metadata location**: `force-app/main/default/aiEvaluationDefinitions/`
**File suffix**: `.aiEvaluationDefinition-meta.xml`

### Test Result Verdicts

Each test case receives verdicts on:
- **Topic selection accuracy** -- did the agent route to the expected topic?
- **Action sequence correctness** -- did the agent invoke the expected actions in order?
- **Response quality** -- does the outcome match the expected description?
- **Custom evaluations** -- optional JSONPath assertions for specific values

## SF CLI Agent Commands

These are the commands the plugin may wrap (via shell execution or `@salesforce/core`):

| Command | Purpose |
|---|---|
| `sf agent test run --api-name <name> --target-org <org> --wait <min>` | Run batch test |
| `sf agent test run --result-format json --output-dir <dir>` | Run with machine-parseable output |
| `sf agent test results --job-id <id> --target-org <org>` | Get results of completed run |
| `sf agent test resume --job-id <id> --target-org <org>` | Resume async test |
| `sf agent test list --target-org <org>` | List available tests |
| `sf agent preview start --target-org <org> --name <agent>` | Start preview session |
| `sf agent preview send --session-id <id> --message <msg>` | Send preview message |
| `sf agent preview end --session-id <id>` | End preview session |
| `sf org list --json` | List authenticated orgs |
| `sf org display --target-org <alias> --json` | Get org details + access token |

Output format flags: `--result-format json|human|junit|tap`

## Authentication Details

### OAuth Scopes Required for Agent API

| Scope | Label | Required |
|---|---|---|
| `api` | Manage user data via APIs | Yes |
| `chatbot_api` | Access chatbot services | Yes |
| `sfap_api` | Access Salesforce API Platform | Yes |
| `refresh_token` | Perform requests at any time | Yes |

### Plugin Auth Pattern (via @salesforce/core)

```typescript
import { Org, AuthInfo } from '@salesforce/core';

// List available orgs
const authFiles = await AuthInfo.listAllAuthorizations();

// Connect to a specific org
const org = await Org.create({ aliasOrUsername: targetOrg });
await org.refreshAuth();
const conn = org.getConnection();

// Ready to use
const accessToken = conn.accessToken;
const instanceUrl = conn.instanceUrl;
```

### Token Security

- Tokens stored as AES-256-GCM encrypted JSON files in `~/.sfdx/`
- Encryption key in `~/.sfdx/key.json` (auto-generated)
- `org.refreshAuth()` handles expired tokens transparently
- Plugin never stores, logs, or transports tokens
